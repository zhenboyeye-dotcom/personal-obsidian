# STM32F103Cx - Medium-density MCU

## 一句话总结

> STMicroelectronics STM32F1 系列 ARM Cortex-M3 微控制器，LQFP48 封装，主频 72MHz，128KB Flash + 20KB SRAM，集成 2×ADC / 3×USART / 2×SPI / 2×I2C / 1×CAN / 1×USB，适用于工业控制、消费电子、手持设备等场景。

---

## 关键参数速查

| 参数 | 值 |
|------|-----|
| 内核 | ARM Cortex-M3 @ 72MHz |
| Flash | 64~128KB |
| SRAM | 20KB |
| 供电电压 | 2.0~3.6V |
| ADC | 2× 12-bit, 1µs, 16通道 |
| 定时器 | 3× 通用16位 + 1× 高级PWM + 2× 看门狗 |
| 通信 | 3× USART / 2× SPI / 2× I2C / 1× CAN / 1× USB |
| DMA | 7通道 |
| IO | 26~80（依封装） |
| 封装 | LQFP48 / LQFP64 / LQFP100 / BGA |

## 初始化模板（GPIO + USART）

### 1. 时钟配置
```c
RCC->APB2ENR |= RCC_APB2ENR_IOPAEN | RCC_APB2ENR_USART1EN;
```

### 2. GPIO 配置（PA9=TX, PA10=RX）
```c
// PA9 = USART1_TX (复用推挽输出 50MHz)
// PA10 = USART1_RX (浮空输入)
GPIOA->CRH = (GPIO_CRH_MODE9_1 | GPIO_CRH_MODE9_0 | GPIO_CRH_CNF9_1);  // AF PP 50MHz
GPIOA->CRH &= ~(GPIO_CRH_CNF9_0);
GPIOA->CRH = (GPIO_CRH_MODE10_0 | GPIO_CRH_CNF10_0);  // 浮空输入
```

### 3. USART1 参数配置
```c
USART1->CR1 = 0;
USART1->BRR = 72000000 / 115200;  // 72MHz / 115200 ≈ 0x271
USART1->CR1 |= USART_CR1_TE | USART_CR1_RE;
```

### 4. USART 使能
```c
USART1->CR1 |= USART_CR1_UE;
```

## 隐藏坑点

| # | 分类 | 问题 | 后果 | 规避 |
|---|------|------|------|------|
| 1 | 时钟 | APB2≤72MHz，APB1≤36MHz | 外设不工作 | 检查 RCC 分频 |
| 2 | 中断 | USART RXNE 中断需先清 TXE | 数据帧错误 | 使能 USART 前配置完 CR1 |
| 3 | DMA | DMA 通道复用冲突 | 数据错乱 | 先配 DMA Channel，再使能外设 |
| 4 | USB | USB 时钟必须 48MHz | 枚举失败 | 配置 PLL 输出 48MHz |
| 5 | 电源 | 2.0V 以下复位 | 上电死机 | 配置 PVD + BOR |
| 6 | BOOT | BOOT0/BOOT1 决定启动模式 | 无法调试 | 确认 BOOT 引脚电平 |
| 7 | GPIO | PC13~15 驱动能力仅 3mA | LED 不亮/IO损坏 | 仅用作低速输入输出 |
| 8 | 复位 | 外设寄存器复位值非全部为 0 | 残留配置异常 | 初始化前全部清零 |
