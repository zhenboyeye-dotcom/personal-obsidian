## 1. 外设一句话总结

> **STM32F103Cx** 是 STMicroelectronics STM32F1 系列 ARM Cortex-M3 微控制器，LQFP48 封装，主频 72MHz，128KB Flash + 20KB SRAM，集成 2xADC / 3xTIM / 3xUSART / 2xSPI / 2xI2C / 1xCAN / 1xUSB，适用于工业控制、消费电子、手持设备等场景。

## 3. 初始化标准步骤（以 GPIO + USART 为例）

### 3.1 时钟配置
```c
// 1. 使能 GPIOA 和 USART1 时钟
RCC->APB2ENR |= RCC_APB2ENR_IOPAEN | RCC_APB2ENR_USART1EN;
```

### 3.2 GPIO 配置
```c
// PA9 = USART1_TX (复用推挽输出)
// PA10 = USART1_RX (浮空输入)
GPIOA->CRH = (GPIO_CRH_MODE9 | GPIO_CRH_CNF9_1);  // 输出 50MHz AF PP
GPIOA->CRH &= ~(GPIO_CRH_CNF9_0);                  // CNF9 = 10 (AF PP)
GPIOA->CRH = (GPIO_CRH_MODE10 | GPIO_CRH_CNF10_0); // 输入浮空
```

### 3.3 USART1 参数配置
```c
USART1->CR1 = 0;
USART1->BRR = 72000000 / 115200;  // 72MHz / 115200 ≈ 0x271
USART1->CR1 |= USART_CR1_TE | USART_CR1_RE;  // 发送使能 + 接收使能
```

### 3.4 USART 使能
```c
USART1->CR1 |= USART_CR1_UE;  // USART 使能
```

## 4. 隐藏坑点 (Notes & Warnings)

| # | 分类 | 问题描述 | 后果 | 规避方法 |
|---|------|----------|------|----------|
| 1 | 时钟 | APB2 时钟最高 72MHz，APB1 最高 36MHz；超过会死机 | 外设不工作 | 确认 RCC 时钟分频配置 |
| 2 | 中断 | USART RXNE 中断需先清 TXE，否则首位丢失 | 数据帧错误 | 在使能 USART 前配置好所有 CR1 位 |
| 3 | DMA | DMA 通道与外设复用，需避免同一通道同时请求 | 数据错乱 | 先配 DMA Channel，再使能外设 |
| 4 | USB | USB 时钟必须为 48MHz，需配置 PLL 输出 | USB 枚举失败 | 使用 RCC 配置 PLL 输出 48MHz |
| 5 | 电源 | 2.0V 以下复位，需等待电压稳定 | 上电死机 | 配置 PVD + BOR |
| 6 | BOOT | BOOT0/BOOT1 决定启动模式，配置错误无法调试 | 无法连接调试器 | 确认 BOOT 引脚电平 |
| 7 | GPIO | PC13/PC14/PC15 驱动能力有限（3mA），不能驱动 LED | LED 不亮或损坏 IO | 仅用作低速输入输出 |
| 8 | 复位 | 所有外设寄存器复位值需查 RM，非全部为 0 | 残留配置导致异常 | 初始化前全部清零 |

|------|-----|
| 内核 | ARM Cortex-M3 |
| 主频 | 72 MHz（1.25 DMIPS/MHz）|
