## 1. 外设一句话总结

> STM32G030 是 STMicroelectronics STM32G0 系列 MCU 上的 ARM Cortex-M0+ 微控制器，主要功能：支持最高 64KB Flash / 8KB SRAM、2x USART / 2x I2C / 2x SPI、多通道 ADC / DMA、低功耗模式，面向通用嵌入式控制场景。

## 2. 关键外设参数

### 2.1 芯片型号对照表

| 型号 | Flash | SRAM | GPIO | ADC 通道 | 封装引脚 |
|------|-------|------|------|---------|---------|
| STM32G030_J6 | 32KB | 8KB | 5 | 5+2 | 8 |
| STM32G030_F6 | 32KB | 8KB | 17 | 14+2 | 20 |
| STM32G030_K6 | 32KB | 8KB | 29 | 16+2 | 32 |
| STM32G030_K8 | 64KB | 8KB | 43 | 16+3 | 48 |
| STM32G030_C6 | 32KB | 8KB | 5 | 5+2 | 8 |
| STM32G030_C8 | 64KB | 8KB | 43 | 16+3 | 48 |

### 2.2 核心参数

| 参数 | 值 |
|------|-----|
| 内核 | ARM Cortex-M0+, 最高 64 MHz |
| 工作电压 | 2.0 V ~ 3.6 V |
| 工作温度 | -40°C ~ 85°C (环境) / -40°C ~ 105°C (结温) |
| Flash | 最高 64 KB, 支持读写保护 |
| SRAM | 8 KB, 硬件奇偶校验 |
| DMA | 5 通道, 灵活外设映射 |

### 2.3 外设资源一览

| 类别 | 外设 | 数量/规格 |
|------|------|----------|
| 定时器 | 高级控制 (16-bit) | 1 |
| 定时器 | 通用 (16-bit) | 4 |
| 定时器 | SysTick | 1 |
| 定时器 | 看门狗 (独立/窗口) | 2 |
| 通信 | I2C (Fast-mode Plus 1Mbit/s) | 2 |
| 通信 | USART (同步 SPI, ISO7816) | 2 |
| 通信 | SPI (最高 32 Mbits/s) | 2 (1 可配置为 I2S) |
| 模拟 | 12-bit ADC (0.4µs) | 最多 16 路外部通道 |
| 其他 | RTC (日历+闹钟+唤醒) | 是 |
| 其他 | CRC 计算单元 | 是 |
| 其他 | 5V 容忍 IO | 多数 IO 支持 |

### 2.4 时钟管理

| 时钟源 | 规格 |
|--------|------|
| 外部高频晶振 | 4 ~ 48 MHz |
| 外部低频晶振 | 32.768 kHz (带校准) |
| 内部高频 RC | 16 MHz (可选 PLL) |
| 内部低频 RC | 32 kHz (±5%) |

### 2.5 低功耗模式

- **Sleep**：CPU 停止，外设运行
- **Stop**：所有时钟停止，支持 RTC/唤醒
- **Standby**：深度睡眠，VBAT 维持 RTC

## 4. Notes & Warnings

| # | 分类 | 问题描述 | 后果 | 规避方法 |
|---|------|----------|------|----------|
| 1 | 电源 | VDD 超过 4.0V 会造成永久损坏 | 器件损毁 | 确保供电不超过 3.6V 额定值 |
| 2 | IO | FT_xx 引脚承受 >4V 时内部上下拉必须关闭 | Latch-up 风险 | 高电压应用加限流电阻 |
| 3 | 复位 | 无专门 BOR，依赖 POR/PDR | 低电压工况不稳定 | 设计时留足电压裕量 |
| 4 | 寄存器 | 本 datasheet 不含寄存器级定义 | 编程需参考 RM | 需查阅 STM32G0 Reference Manual 获取寄存器详情 |
| 5 | Flash | Flash 写保护需通过 option bytes 配置 | 可能锁死调试 | 首次配置 option bytes 需谨慎 |

## 5. 初始化标准步骤（状态机参考）

### 3.1 时钟配置
```
1. 使能外设时钟 (RCC->IOPENR |= GPIOXEN)
2. 等待时钟就绪标志
3. 配置系统时钟源 (RCC->CR / CFGR)
```

### 3.2 GPIO 配置
```
1. 配置 GPIO 模式 (MODER)
2. 设置输出类型/速度 (OTYPER/OSPEEDR)
3. 配置上下拉 (PUPDR)
```

### 3.3 外设参数配置
```
[外设]->CR1  = 控制字;
[外设]->CFG  = 参数;
```

### 3.4 使能
```
[外设]->CR1  |= 使能位;
```
