# W25Q64JV — 64Mbit Serial Flash Memory

## 一句话总结

> Winbond W25Q64JV 是一款 64Mbit (8MB) 串行 Flash 芯片，支持标准/Dual/Quad SPI，3.3V 供电，最低 100K 擦写循环，20年数据保留，适用于代码存储、参数存储、XIP 直接执行。

| 位 | 名称 | 说明 |
|----|------|------|

| S5~S6 | TB, SEC | 顶/底保护、扇区保护 |

| 位 | 名称 | 说明 |
|----|------|------|

## 常用操作时序

### 读取 JEDEC ID
```
/CS LOW → 0x9F → Read 3 bytes (MF7-0, ID15-8, ID7-0) → /CS HIGH
→ Returns: EF 40 17 (Winbond, W25Q64JV)
```

### 读取数据（标准SPI）
```
/CS LOW → 0x03 → 3-byte addr → Read bytes → /CS HIGH
```

### 页面编程（256B）
```
1. Write Enable: /CS→0x06→/CS
2. Page Program: /CS→0x02→3B addr→data(≤256B)→/CS
3. Wait BUSY=0 (read 0x05)
```

### 扇区擦除（4KB）
```
1. Write Enable: /CS→0x06→/CS
2. Sector Erase: /CS→0x20→3B addr→/CS
3. Wait BUSY=0 (~45ms)
```

### 深度省电
```
/CS→0xB9→/CS
唤醒: /CS→0xAB→/CS
```

## STM32 使用示例

### 硬件连接（SPI1）

| W25Q64JV | STM32 |
|---------|-------|
| /CS | PA4 (GPIO) |
| DI (IO0) | PA7 (MOSI) |
| DO (IO1) | PA6 (MISO) |
| CLK | PA5 (SCK) |
| /WP, /HOLD | VCC (或 GPIO) |

### 基本读写

```c
#define W25Q64_JEDEC_ID 0xEF4017

// 读取 JEDEC ID
uint32_t w25q64_read_id(void) {
    uint8_t buf[3];
    SPI1->CR1 |= SPI_CR1_SPE;
    CS_LOW();
    SPI1->DR = 0x9F;
    while (!(SPI1->SR & SPI_SR_TXE));
    while (SPI1->SR & SPI_SR_BSY);
    buf[0] = SPI1->DR;  // dummy
    SPI1->DR = 0xFF;
    while (!(SPI1->SR & SPI_SR_RXNE));
    buf[0] = SPI1->DR;  // Manufacturer
    SPI1->DR = 0xFF;
    while (!(SPI1->SR & SPI_SR_RXNE));
    buf[1] = SPI1->DR;  // Device ID high
    SPI1->DR = 0xFF;
    while (!(SPI1->SR & SPI_SR_RXNE));
    buf[2] = SPI1->DR;  // Device ID low
    CS_HIGH();
    return (buf[0] << 16) | (buf[1] << 8) | buf[2];
}

// 读取数据
void w25q64_read(uint8_t* buf, uint32_t addr, uint32_t len) {
    CS_LOW();
    SPI1->DR = 0x03;
    SPI1->DR = (addr >> 16) & 0xFF;
    SPI1->DR = (addr >> 8) & 0xFF;
    SPI1->DR = addr & 0xFF;
    while (len--) {
        SPI1->DR = 0xFF;
        while (!(SPI1->SR & SPI_SR_RXNE));
        *buf++ = SPI1->DR;
    }
    CS_HIGH();
}

// 写使能
void w25q64_write_enable(void) {
    CS_LOW();
    SPI1->DR = 0x06;
    while (!(SPI1->SR & SPI_SR_TXE));
    while (SPI1->SR & SPI_SR_BSY);
    CS_HIGH();
}

// 扇区擦除（4KB）
void w25q64_sector_erase(uint32_t addr) {
    w25q64_write_enable();
    CS_LOW();
    SPI1->DR = 0x20;
    SPI1->DR = (addr >> 16) & 0xFF;
    SPI1->DR = (addr >> 8) & 0xFF;
    SPI1->DR = addr & 0xFF;
    while (!(SPI1->SR & SPI_SR_TXE));
    while (SPI1->SR & SPI_SR_BSY);
    CS_HIGH();
    // Wait erase complete
    while (w25q64_read_status() & 0x01);
}
```

## 隐藏坑点

1. ⚠️ **写入前必须 Write Enable** — 每次擦/写/编程前必须发 0x06，否则命令被忽略
2. ⚠️ **BUSY 期间所有命令被忽略** — 除了 Read Status Register (0x05)，其他命令在 BUSY=1 时不响应
3. ⚠️ **Quad 模式需使能 QE 位** — SR2 bit 9 (QE) 设为 1 后 /WP=/HOLD 才变成 IO2/IO3
4. ⚠️ **扇区地址对齐** — Sector Erase (0x20) 的地址必须 4KB 对齐，否则只有低对齐地址部分被擦
5. ⚠️ **掉电保护** — 上电后默认所有扇区 unlocked，但 /WP 脚拉低会锁定 SR，写入前确保 WEL=1 后再操作
6. ⚠️ **/CS 上电/掉电时必须跟踪 VCC** — 否则可能意外写入，建议 /CS 接上拉电阻
7. ⚠️ **擦除时间较长** — Sector Erase ~45ms，Block Erase ~150ms，Chip Erase ~20s，轮询 BUSY 位
8. ⚠️ **超过256字节自动回卷** — Page Program 一次最多 256 字节，超出后地址回绕到页首
