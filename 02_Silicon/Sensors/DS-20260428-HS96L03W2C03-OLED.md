## I2C 通信格式

### 从机地址

```
0x3C (SA0=0, 默认)
0x3D (SA0=1)
```

### 写操作时序

```
S [0x3C][W] A [0x00] A [命令/数据] A P
S [0x3C][W] A [0x40] A [数据字节] A P
```

- **0x00**：下一个字节是命令
- **0x40**：下一个字节是数据

### I2C 时序参数

| 参数 | 最小 | 最大 | 单位 |
|------|------|------|------|
| 时钟周期 tcycle | 2.5 | - | µs |
| 起始条件保持时间 | 0.6 | - | µs |
| 数据建立时间 | 100 | - | ns |
| 停止条件建立时间 | 0.6 | - | µs |
| 时钟/数据上升时间 | - | 300 | ns |
| 时钟/数据下降时间 | - | 300 | ns |

## 初始化代码（STM32 I2C）

```c
// OLED I2C 地址 (SA0=0)
#define OLED_ADDR 0x3C

// I2C 写一个字节到 OLED
void OLED_WR_Byte(uint8_t dat, uint8_t cmd) {
    I2C_Start();
    I2C_Send_Byte(OLED_ADDR << 1);  // 写地址
    I2C_Wait_Ack();
    I2C_Send_Byte(cmd ? 0x40 : 0x00);  // 数据=0x40, 命令=0x00
    I2C_Wait_Ack();
    I2C_Send_Byte(dat);
    I2C_Wait_Ack();
    I2C_Stop();
}

// OLED 初始化
void OLED_Init(void) {
    delay_ms(200);
    OLED_WR_Byte(0xAE, 0);  // 关闭显示
    OLED_WR_Byte(0x00, 0);  // 低列地址
    OLED_WR_Byte(0x10, 0);  // 高列地址
    OLED_WR_Byte(0x40, 0);  // 起始行地址
    OLED_WR_Byte(0x81, 0);  // 对比度
    OLED_WR_Byte(0xCF, 0);  // 对比度值
    OLED_WR_Byte(0xA1, 0);  // SEG映射
    OLED_WR_Byte(0xC8, 0);  // COM扫描方向
    OLED_WR_Byte(0xA6, 0);  // 正常显示
    OLED_WR_Byte(0xA8, 0);  // 多路复用比
    OLED_WR_Byte(0x3F, 0);  // 1/64
    OLED_WR_Byte(0xD3, 0);  // 显示偏移
    OLED_WR_Byte(0x00, 0);
    OLED_WR_Byte(0xD5, 0);  // 时钟分频
    OLED_WR_Byte(0x80, 0);
    OLED_WR_Byte(0xD9, 0);  // 预充电
    OLED_WR_Byte(0xF1, 0);
    OLED_WR_Byte(0xDA, 0);  // COM引脚
    OLED_WR_Byte(0x12, 0);
    OLED_WR_Byte(0xDB, 0);  // VCOMH
    OLED_WR_Byte(0x30, 0);
    OLED_WR_Byte(0x20, 0);  // 页寻址模式
    OLED_WR_Byte(0x02, 0);
    OLED_WR_Byte(0x8D, 0);  // 电荷泵
    OLED_WR_Byte(0x14, 0);  // 开启DC/DC
    OLED_Clear();
    OLED_WR_Byte(0xAF, 0);  // 开启显示
}
```

## 显存映射

SSD1306 有 128×8 = 1024 bytes 显存，分为 8 页（每页 128 字节）：

```
页0 → OLED屏幕行 1~8
页1 → OLED屏幕行 9~16
...
页7 → OLED屏幕行 57~64
```

写显存：`OLED_WR_Byte(0xB0 + page, 0)` 选页，然后连续写入 128 字节数据。

## 隐藏坑点

1. ⚠️ **VCC 需要 7V 以上才能点亮** — 内置 DC/DC 升压需要 VBAT≥2.8V，但实际显示需要 7V+，部分模组实际需要 12V（外置）
2. ⚠️ **I2C 地址是 0x3C 不是 0x78** — 一些代码用左移后的 8bit 地址（0x78），但这里 0x3C 是 7bit 地址，写入时左移变 0x78
3. ⚠️ **SDA/SCL 必须接上拉电阻** — I2C 开漏输出，无上拉总线无法工作（通常 4.7kΩ）
4. ⚠️ **初始化最后才开显示** — 先关显示→配置→清屏→最后 0xAF 开显示，否则可能闪屏
5. ⚠️ **进入睡眠模式要先关显示** — 正确的下电顺序：先 0xAE 关显示 → 延时 → 断电
6. ⚠️ **长时间固定图案会残影** — 静态内容建议定期刷新或使用 ScreenSaver 模式
7. ⚠️ **VBAT 供电能力要够** — 内置 DC/DC 升压需要峰值电流，STM32 GPIO 驱动能力可能不足，建议单独供电或加电容
8. ⚠️ **SSD1306 有多种尺寸变种** — 0.96" 128×64 和 0.91" 128×32 驱动代码不完全兼容，页数不同
