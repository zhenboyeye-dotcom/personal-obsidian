# TAS-LTE-4G[E36] — 4G CAT.1 DTU 模组

## 一句话总结

> 塔石物联推出的 CAT.1 4G 透传 DTU 模组，Cortex-M3@204MHz，支持 TCP/UDP/MQTT/HTTP/WebSocket/NTP，3.3~4.3V 供电，双串口。

---

## AT 指令速查

### 基本操作

| 操作 | 指令 | 说明 |
|------|------|------|
| 退出透传 | `+++` | 发送三个字节退出透传模式 |
| 进入透传 | `ATO` | 从命令模式返回透传 |
| 测试 | `AT` | 握手测试 |
| 查询信号 | `AT+CSQ` | 返回: +CSQ: rssi,ber |
| 查询 IMEI | `AT+CGSN` | 查询 IMEI |
| 查询 IMSI | `AT+CIMI` | 查询 IMSI |
| 查询ICCID | `AT+ICCID` | 查询 SIM 卡 ICCID |
| 查询运行时间 | `AT+RUNNINGTIME?` | 返回运行时间戳和剩余内存 |
| ADC采集 | `AT+ADC` | 采集 CPU 温度和供电电压 |

### 工作模式切换

| 指令 | 说明 |
|------|------|
| `AT+NETMODE=1` | TCP 模式 |
| `AT+NETMODE=2` | UDP 模式 |
| `AT+NETMODE=3` | MQTT 模式 |
| `AT+NETMODE=4` | HTTP 模式 |
| `AT+NETMODE=5` | 塔石 DTU 云 |
| `AT+NETMODE=6` | 阿里云直连 |
| `AT+NETMODE=7` | OneNet 直连 |
| `AT+NETMODE=8` | WebSocket |

### MQTT 相关

| 指令 | 说明 |
|------|------|
| `AT+MQTTSUB=?` | 设置订阅主题（最多5个） |
| `AT+MQTTPUB=?` | 设置推送主题（最多2个） |
| `AT+MQTTUSR=?` | 设置用户名/密码 |
| `AT+MQTTCLIENTID=?` | 设置 ClientID |
| `AT+MQTTKEEP=?` | 设置心跳时间 |
| `AT+MQTTQOS=?` | 设置 QoS (0/1/2) |
| `AT+MQTTRETAIN=?` | 保留消息开关 |

### TCP/UDP 连接

| `AT+BACKUP=?` | 设置备用服务器 |
| `AT+HEARTBEAT=?` | 设置心跳包内容 |

| `Network initialization failed!` | 网络初始化失败 |
| `NET STATE UNREGISTER restart!` | SIM 卡掉网 |
| `DSCTimeout restart!` | 网络连接超时 |

## 网络缓存策略

- **缓存使能**: `AT+CACHE=1`（默认开启）
- **缓存关闭**: `AT+CACHE=2`
- 4通道共享 **50K 或 50条**
- 串口缓存有 **10条动态区**，实际 50~60条
- 设备未连接服务器时，串口数据存入缓存

---

## 双卡单带策略

| 策略号 | 说明 |
|--------|------|
| 0 | 自动切换：优先 SIM0，掉线切 SIM1；每月2号尝试切回 SIM0 |
| 1 | 仅使用 SIM0（插拔卡） |
| 2 | 仅使用 SIM1（贴片卡） |

> ⚠️ E36 **不支持低功耗**，注意供电电流设计。

---

## 隐藏坑点

1. ⚠️ **不支持低功耗** — 静止电流 3.8mA，电池供电需额外注意
2. ⚠️ **TTL 3.0V 电平** — 与 5V 系统连接需电平转换
3. ⚠️ **MQTT 订阅失败会一直离线** — 某个主题订阅不上会阻塞其他主题
4. ⚠️ **UDP 模式下超时重启/备用服务器无效**
5. ⚠️ **串口缓存满时旧数据丢弃** — 50条动态阈值
6. ⚠️ **JSON 数据点关键字需与设备配置完全对应**
7. ⚠️ **双卡单带默认策略是自动切换** — 定向卡需注意 SIM 卡策略配置
8. ⚠️ **DNS 查询可能失败** — 生产环境建议用 IP 而不是域名
