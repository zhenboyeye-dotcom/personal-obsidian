## 3. 初始化标准步骤（状态机）

### 3.1 时钟配置
```
1. 使能外设时钟 (RCC->ENR |= BITx)
2. 等待就绪标志 (while(!(RCC->ENR & BITx)))
```

### 3.2 引脚复用
```
1. 配置 GPIO 模式为复用功能 (AF0~AF15)
2. 对应 AF 选择寄存器 (AFRL / AFRH)
```

### 3.3 外设参数配置
```
CR  →  [工作模式: Tx/Rx, 波特率, 数据位, 停止位, 校验]
BRR →  [USARTDIV / 波特率分频系数]
```

### 3.4 使能
```
CR  →  UE=1 (USART 使能)
SR  →  等待 TXE=1 (发送完成)
```
